# NoxClips AI

A free, browser-based starter editor for videos you own or have permission to edit.

## Run it
Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the root of your GitHub repository. Enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).

## Current features
- Local video upload and preview
- Manual clip start/end selection
- Five evenly spaced section suggestions (not AI highlight detection)
- 9:16, 1:1, and 16:9 canvas layouts
- Editable hook and caption overlays
- Browser-based recording export where supported

## Limitations
This starter does not download YouTube videos, transcribe speech, detect viral moments with AI, track faces, batch-export five clips, or publish directly to social platforms. Export format depends on browser support (MP4 when supported, otherwise WebM). Large videos may exceed mobile browser memory. Keep the page open during export.
